# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in zcp-ddns, please do **not** open a public GitHub issue.

Instead, report it privately by email to [security@zsoftly.ca](mailto:security@zsoftly.ca) or through [GitHub Security Advisories](https://github.com/zsoftly/zcp-ddns/security/advisories/new).

We will acknowledge receipt within 3 business days and work with you to resolve the issue promptly.

## Scope

This policy covers the zcp-ddns service and its source code in this repository.

It does **not** cover the ZSoftly Cloud Platform API itself. Report API security issues to [security@zsoftly.ca](mailto:security@zsoftly.ca).

## Supported Versions

During early development, security fixes are addressed on `main`. After the first stable release, support covers the latest stable release only.
