# Code of Conduct Summary

This file summarizes the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which applies to this project.

In short: be respectful, be constructive, and assume good faith. Harassment, personal attacks, and discriminatory behavior are not tolerated anywhere the project operates, including GitHub and the community Slack.

## Reporting

Keep reports private. Send them to [community@zsoftly.ca](mailto:community@zsoftly.ca). Reports involving a maintainer are escalated to ZSoftly.

## Enforcement

Maintainers may remove comments, reject contributions, or ban contributors for behavior violating this code of conduct. Actions should be proportionate to the violation.
